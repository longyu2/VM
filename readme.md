# 新增功能
---
各文件介绍，
#### vm_bf.js 
运行一个bf文件，可以携带一个输入，硬编码在vm_bf.js文件里，.bf文件默认用vm_bf.js运行

#### vm.js
 原始版本，只能接受.bf1 文件,不能运行 .bf 文件，但是.bf1 文件可以 嵌入 bf 语法，前提是
每一行只有一个bf符号，不能连写，因为bf1文件是按行来执行的，.bf1 文件默认用 vm.js运行
#### vm2.js
 为了bf自举的测试版，它只会把输入的源代码转化成数字加载到内存中，例如  node vm2 b.bf1 并不会运行b.bf1,
 它只会把b.bf1加载到内存，vm2 真正执行的是 ./src/runtime.bf1 。vm2 是实验性质，虽然已经暂停研发，留待未来继续
 尝试bf自举使用。没有文件默认用vm2.js运行。

#### bfToC.js 
能将bf 编译为简单的C，可以编译bf.bf这种bf自解释器，它的输入是命令行参数，但只接受一个输入，会去读取文件
用法为 node bftoC.js a.bf a.c ，接受两个参数，第一个是bf源文件，第二个是 输出的.c 文件，将.c 编译成exe
后可以运行，运行时接受一个参数，会读取这个参数的文件内容，作为程序的输入
用法： 
gcc a.c -o a     
./a test.bf 
a.c是由a.bf 编译而来，a.bf 是一个用bf写的bf解释器，能运行不带输入的bf程序

#### t.js
封装工具函数 bfToVM，将bf转成bf1的格式，是vm2 能在bf1 里夹杂bf能力的来源
