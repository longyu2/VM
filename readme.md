### 指令集 ：


push 往内存中写数

left/right 指针移动

start/end，成对出现，当指针所在区域数为0，跳转到end，不为零，执行代码块

add 将当前指针内容增加数据

fun 函数，执行fun里的一段代码

### 自举设计
尝试写一段程序自举图灵机，但是我发现一个问题，就是使用js设计的图灵机太过强大，所以通用图灵机的构造相当困难
所以是否可以简化一些设计，来使得自举更容易？

所以，削弱一些指令的功能，例如函数，例如add等
指令本身也不能用字符串了，就用数字表示即可


// 写出 js 编译为中间代码 的编译器
// 然后就可以把 虚拟机js 进行编译，得到虚拟机的中间代码

// 然后就可以用虚拟机执行此虚拟机的中间代码
// 也就是通用图灵机


// 另一种办法是直接使用中间代码编写一个虚拟机出来，然后用原始虚拟机直接执行此中间代码编写的虚拟机，也可以达到通用图灵机的效果

// 由于，用js写的虚拟机已经实现，所以难度低

// 现在的问题就是，到底是写出编译器更难，还是用中间代码写出虚拟机更难

// 我在不断为虚拟机增加js代码，就是增加我用中间代码写出此虚拟机的难度
